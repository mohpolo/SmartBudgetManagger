# SmartBudget Manager
project for managing Budget
**Student:** Mohamed Amin Bouachria  
**Group:** 6

SmartBudget Manager is an Excel workbook for tracking income and expenses. It calculates totals and the monthly balance, shows spending by category, and displays budget status.

**What you need:** Excel 2016 or newer, or a compatible spreadsheet program.

**Getting started**
1. Open `SmartBudget_Manager.xlsx`.
2. Select **Transactions**.
3. Enter the date, description, and amount in the correct columns.
4. Select a category for each expense.
5. Open **Dashboard** to check totals, balance, budget status, and the chart.
6. Save your changes.

Enter data carefully and keep a backup of your file.
